# Second Brain — Local GPU env for Qwen3 fine-tune inference / fine-tuning on Windows.
#
# Works for BOTH the 0.6B local fine-tune path and the 1.7B fine-tuned adapter
# inference path. This env can also host the Flask dogfooding surface for the
# fine-tuned parser integration. Same Unsloth + bitsandbytes + peft + CUDA-torch stack.
#
# Tested on:
#   Windows 11, GTX 1650 (4 GB), driver 555.99 (CUDA 12.5),
#   Python 3.10.5, torch 2.6.0+cu124.
#
# IMPORTANT — install order matters. `pip install -r` of this file ALONE is
# not enough; CUDA torch and Unsloth need separate index URLs and a
# triton-windows pin. Use the steps in the matching PowerShell setup script
# (`create_local_qwen3_finetuned_env.ps1`) or follow these steps manually:
#
#   1.  py -3.10 -m venv .venv-qwen3-1p7b-1650
#   2.  .\.venv-qwen3-1p7b-1650\Scripts\Activate.ps1
#   3.  python -m pip install --upgrade pip setuptools wheel
#   4.  python -m pip install torch torchvision torchaudio \
#         --index-url https://download.pytorch.org/whl/cu124      # match driver
#   5.  python -m pip install "unsloth[windows] @ git+https://github.com/unslothai/unsloth.git"
#   6.  python -m pip install --force-reinstall --no-deps torch torchvision torchaudio \
#         --index-url https://download.pytorch.org/whl/cu124      # Unsloth pulls CPU torch; force CUDA back
#   7.  python -m pip install "triton-windows==3.1.0.post17"      # match torch 2.6 ABI (newer triton breaks _inductor)
#   8.  python -m pip install -r requirements_local_qwen3_finetuned_windows.txt
#
# CUDA index URL guide:
#   driver supports CUDA 12.8+ → use cu128
#   driver supports CUDA 12.4–12.7 → use cu124  (this machine: 12.5)
#   driver supports CUDA 12.1–12.3 → use cu121
#   check with: nvidia-smi   (see "CUDA Version" header)
#
# Why these pins:
#   torch 2.6.0+cu124       — last torch line that ships cu124 wheels with the older _inductor API
#   triton-windows 3.1.0.x  — has `AttrsDescriptor` that torch 2.6 expects. Newer 3.6.x removed it.
#   unsloth latest (git)    — official Windows install path documented by Unsloth
#   transformers 5.5.0      — pulled by Unsloth latest; do not downgrade
#   peft 0.19.1             — adapter loading API used by evaluate_finetune.py
#   bitsandbytes 0.49.2     — 4-bit quantization (1.7B fits in ~1 GB VRAM at 4-bit on the 1650)
